## Подготовка к тестированию

1. **Откройте браузер** по адресу: http://localhost:8082/
2. **Откройте DevTools** (F12 или Cmd+Option+I на Mac)
3. **Перейдите на вкладку Console**

## Возможные проблемы и что проверить

### Проблема 1: Инструмент не создается при клике на график

**Симптомы:**
- Нет вывода `🏗️ build_tool called`
- Или есть сообщение `⏭️ Skipped: ...`

**Возможные причины:**
1. `cursor.mode !== 'explore'` - курсор в неправильном режиме
2. `cursor.lock_tool` - инструмент заблокирован
3. `this.data.tool === 'Cursor'` - выбран курсор вместо инструмента
4. `this.data.drawingMode === true` - уже в режиме рисования

**Решение:**
Проверьте вывод в `grid_mousedown` и найдите, какая проверка не прошла.

### Проблема 2: Pin не обновляется при движении мыши

**Симптомы:**
- Нет вывода `📍 Pin.update()`

**Возможные причины:**
1. Pin не создался при инициализации инструмента
2. Событие mousemove не подписано

**Решение:**
Проверьте, вызывается ли метод `init()` в LineTool при монтировании.

### Проблема 3: change-settings вызывается, но settings не обновляются

**Симптомы:**
- Есть вывод `🔧 change_settings called`
- Но `p1` и `p2` остаются `null`

**Возможные причины:**
1. Проблема с реактивностью Vue 3 в методе `merge()`
2. Неправильный путь к settings

**Решение:**
Проверьте вывод "After merge - full data" и убедитесь, что данные действительно обновились.

### Проблема 4: Линия не отрисовывается на canvas

**Симптомы:**
- Pin обновления работают корректно
- `p1` и `p2` установлены
- Но линия не видна на графике

**Возможные причины:**
1. Метод `draw()` не вызывается
2. Значения `p1` и `p2` не передаются в computed свойства
3. Canvas не перерисовывается

**Решение:**
Добавьте логирование в метод `draw()` LineTool:
```javascript
draw(ctx) {
    console.log('🎨 LineTool.draw():', {
        p1: this.p1,
        p2: this.p2,
        sett: this.sett
    })
    if (!this.p1 || !this.p2) {
        console.warn('   ⚠️ Skipped: p1 or p2 is null')
        return
    }
    // ... rest of draw code
}
```
